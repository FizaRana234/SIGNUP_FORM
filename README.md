## Sign-Up Form — Full Stack Web Project
A fully functional user registration form built with a complete frontend 
and backend stack. Includes client-side and server-side validation with 
data stored securely in a MySQL database.

### Features
- Responsive form design using HTML and CSS
- PHP backend for form processing and server-side validation
- MySQL database integration for storing user records
- Input validation and basic error handling

### Technologies Used
- HTML5
- CSS3
- PHP
- MySQL
